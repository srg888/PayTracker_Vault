## Базовые отчёты
- Количество заявок за период, в разрезе:
  - каждого Исполнителя ([[03. Назначение исполнителя|Назначение исполнителя]])
  - каждого Заказчика
  - каждого агента ([[Агенты]])
  - подразделения / юрлица Заказчика
  - типа заявки (платёж / закупка / консультация)

## Дополнительные отчёты
- Суммы платежей за период в разрезе валют, юрлиц заказчика, агентов (на основе фактической суммы в рублях на дату исполнения, см. [[08. Фактическое исполнение платежа|Фактическое исполнение платежа]] и [[01. Поля заявки — Платёж|Поля заявки — Платёж]]).
- Просроченные заявки — факт исполнения vs "Ожидаемый срок исполнения".
- Среднее время обработки заявки по типу заявки (от "Новая заявка" до "Закрыта", см. [[Статусы заявки]]) — для контроля SLA.
- Количество заявок, прошедших через статус "Уточнение" (см. [[06. Уточнение|Уточнение]]) — индикатор качества исходных данных от Заказчиков.
- Полная история одной заявки (выгрузка из [[Аудит]]) — для разбора спорных ситуаций.

## Список заявок — автофильтр по колонкам (реализовано)
Страница `/requests` (список заявок на экране, не выгрузка) имеет построчный автофильтр по каждой колонке таблицы — по образцу автофильтра Excel: клик по иконке-воронке в заголовке колонки открывает выпадающий список: заголовок колонки, поле поиска по значениям, флажок «Сортировать по возрастанию», чек-бокс-список всех различных значений, встречающихся в этой колонке среди уже загруженных строк, ссылки «(Выделить все)» / «(Снять все)» и кнопки «OK» / «Отмена»; можно оставить отмеченными только нужные значения и нажать «OK». Панель одна на всю таблицу и открывается под кнопкой той колонки, по которой нажали: у правого края окна она прижимается внутрь, у нижней границы открывается вверх, закрывается повторным кликом по воронке, кликом вне панели или клавишей Esc; активная воронка подсвечивается — строки, не подходящие под отметку хотя бы по одной колонке, скрываются. Фильтры по разным колонкам комбинируются одновременно (пересечение условий). Счётчик «Показано N из M» и кнопка «Сбросить фильтры» — над таблицей.

Панель фильтра — всплывающий слой (`position: fixed`, z-index выше таблицы), а не элемент потока страницы: она открывается поверх содержимого под кнопкой нажатой колонки, прижимается внутрь у краёв окна, открывается вверх у нижней границы и не занимает места в разметке (в HTML помечена атрибутом `hidden`, который снимается при открытии). Цвета текста заданы внутри панели явно, чтобы стили заголовков таблицы (`th`) и форм (`label`) не наследовались в её содержимое.

Это чисто экранная фильтрация (скрытие/показ уже отрисованных строк в браузере), без обращения к серверу — весь список заявок и так загружается за один запрос на `/requests`. Отдельно от этого механизма существует серверная фильтрация при формировании выгрузки (см. «Экспорт» ниже и `get_report_fields`/`generate_report_list` в `app/services/reports.py`) — это другой, независимый функционал: автофильтр управляет только тем, что видно на экране прямо сейчас, и не влияет на то, что попадёт в CSV/XLSX при экспорте.

## Экспорт
- Экспорт в xlsx (Excel) — реестр заявок за период с возможностью фильтрации по всем разрезам выше.
- Импорт справочных данных (агенты, компании-покупатели, курсы валют) из xml/csv.

## Правила (см. [[Бизнес-правила]])
- **BR-090.** Отчёты формируются на основании сохранённых данных операций и истории системы.
- **BR-091.** Для финансовых отчётов используются фактически исполненные суммы и сохранённые значения курсов. Текущий курс валюты не должен изменять историческую отчётность.
